# 🚀 OG Testnet Trading Bot

Автоматизированный торговый бот для тестовой сети OG (0G), который выполняет свопы токенов и минтинг тестовых токенов на множественных аккаунтах.

## 📋 Возможности

### 🔄 Автоматические свопы токенов
- **Поддерживаемые пары**: ETH ↔ USDT, BTC ↔ USDT, ETH ↔ BTC, USDT ↔ GIMO, USDT ↔ stOG, USDT ↔ VOG
- **Случайные суммы**: Автоматический выбор случайных сумм для каждой пары токенов
- **Автоматический апрув**: Проверка и автоматическое одобрение токенов перед свопом
- **Ретри-механизм**: При неудаче автоматически пробует другую случайную пару

### 🪙 Минтинг тестовых токенов
- **Поддерживаемые токены**: BTC, ETH, USDT
- **Автоматическая проверка**: Проверяет текущий баланс и новые токены после минта
- **Обработка ошибок**: Понятные сообщения при ограничениях (например, "Подождите 24 часа")

### 👥 Мульти-аккаунт поддержка
- **Последовательное выполнение**: Автоматический переход между аккаунтами
- **Случайные задержки**: 2-5 секунд между транзакциями, 12-17 секунд между аккаунтами

## 🛠 Технологии

- **TypeScript** - Основной язык разработки

## 🚀 Использование

### Запуск случайных свопов для всех аккаунтов
```bash
npm run og:swaps
```

### Запуск минта тестовых токенов для всех аккаунтов
```bash
npm run og:faucet
```

### Запуск одиночного свопа
```bash
npx ts-node src/Og/ogJaineSwap.ts Account4 eth-to-usdt
```

### Запуск минта для одного аккаунта
```bash
npx ts-node src/Og/ogJaineFaucet.ts Account4
```

## 📝 Логирование

Бот предоставляет подробное логирование:
- ✅ Успешные транзакции с хешами
- ⚠️ Предупреждения о неудачных свопах
- 💰 Информация о балансах и суммах
- ⏳ Время ожидания между операциями
- 📊 Прогресс выполнения по аккаунтам

## 🛡️ Безопасность

- **Приватные ключи**: Хранятся в защищенной системе управления ключами
- **Симуляция транзакций**: Все транзакции симулируются перед отправкой
- **Проверка контрактов**: Автоматическая проверка существования контрактов
- **Обработка ошибок**: Детальная обработка всех возможных ошибок

## 🔄 Workflow

1. **Инициализация**: Загрузка приватных ключей и проверка подключения
2. **Случайные свопы**: До 10 попыток случайных свопов на аккаунт
3. **Последовательные свопы**: Проход по всем поддерживаемым направлениям
4. **Переход к следующему аккаунту**: Случайная задержка 12-17 секунд
5. **Повтор**: Для всех 6 аккаунтов

## 📈 Производительность

- **Время на аккаунт**: ~5-10 минут (включая задержки)
- **Общее время**: ~30-60 минут для всех аккаунтов
- **Успешность**: Высокая благодаря retry-механизму и проверкам
